CS2 Esports Tracker - Start Guide

Note: If you're seeing "command not found" errors, try the methods below.

Option 1: Start via Terminal (Recommended)

Open a terminal window and run:

sudo supervisorctl start mongodb backend frontend

Option 2: Use the Start Script

Run the start script in a terminal:

sh /app/START_HERE.sh

Option 3: Run the Simple Shell Script

Run the plain sh script:

sh /app/run.sh

Option 4: Manual Start

Execute these commands one by one in a terminal:

sudo supervisorctl start mongodb
sudo supervisorctl start backend
sudo supervisorctl start frontend

Accessing the Application

Once started, access the application at:

http://localhost:3000

Checking Status

To check if all services are running:

sudo supervisorctl status
